# ۰۳ — نصب و راه‌اندازی

[بازگشت به فهرست](../README.md)

## پیش‌نیازها

برای نصب قواعد، Python 3.9 یا جدیدتر و دسترسی نوشتن به پوشهٔ پروژه لازم است.
نصب‌کننده و اسکنر از کتابخانهٔ استاندارد Python استفاده می‌کنند.
برنامهٔ مقصد می‌تواند هر پشتهٔ رابط وب داشته باشد؛ ادغام هر پشته باید با ساختار موجود انجام شود.

## نصب قواعد در پروژه

از پوشهٔ اصلی بسته، ابتدا پیش‌نمایش را اجرا کنید:

```bash
python3 Bilingual_UI_Rules_Installer.py --project "/path/to/project" --dry-run
```

اگر مسیرها درست بودند:

```bash
python3 Bilingual_UI_Rules_Installer.py --project "/path/to/project"
```

نمونهٔ ویندوز:

```powershell
py .\Bilingual_UI_Rules_Installer.py --project "C:\Projects\MyApp" --dry-run
py .\Bilingual_UI_Rules_Installer.py --project "C:\Projects\MyApp"
```

پوشهٔ پروژه باید از قبل وجود داشته باشد. نصب‌کننده را درون `src` قرار ندهید.
پس از نصب، تغییر فایل‌ها را مرور کنید و در ابزار توسعه بررسی کنید کدام دستورها بارگذاری شده‌اند.

## استفاده از اسکیل‌های بسته

چهار اسکیل قبلاً در حساب فعلی ساخته شده‌اند؛ این ZIP نسخهٔ قابل انتقال آن‌ها را هم دارد.
برای ابزار یا حساب دیگری، از روش رسمی واردکردن اسکیل در همان میزبان استفاده کنید و چهار پوشه را حفظ کنید.
خارج کردن ZIP یا اجرای نصب‌کننده، نصب اسکیل در حساب دیگر را انجام نمی‌دهد.
مستندات `docs` و `templates` را داخل پوشهٔ یک اسکیل کپی نکنید.
اگر ابزار اسکیل را پشتیبانی نمی‌کند، قواعد پروژه و POLICY همان قرارداد را در دسترس می‌گذارند.

## ادغام در برنامه

1. توکن‌های موجود را با قرارداد نگاشت کنید؛ CSS موازی نسازید.
2. CSS نمونه را یک‌بار در نقطهٔ ورودی مناسب و با دامنهٔ کنترل‌شده وارد کنید.
3. مسیر فونت‌ها را به فایل‌های واقعی دارای مجوز متصل کنید.
4. `lang` و `dir` را از زبان معتبر پروژه در سند اولیه تنظیم کنید.
5. تم اولیه را با راهکار سازگار با SSR و CSP پروژه تعیین کنید.
6. `guard.json` را با پوشه‌های واقعی رابط و مسیر دقیق توکن‌ها تنظیم کنید.
7. اسکنر و ماتریس چهارحالته را اجرا کنید و نتیجه را ثبت کنید.

نصب موفق قواعد، به معنی تکمیل این هفت مرحله یا تأیید ظاهر برنامه نیست.
