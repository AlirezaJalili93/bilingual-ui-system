# ۰۵ — قرارداد کامپوننت و توکن‌های طراحی

[بازگشت به فهرست](../README.md)

## لایه‌بندی

| لایه | نمونهٔ مسئولیت |
| --- | --- |
| پایه | فونت، توکن، تم و جهت |
| جزء پایه | Button، Input، Label، Dialog |
| الگو | فیلد کامل فرم، نوار ابزار، جدول و صفحه‌بندی |
| جزء دامنه | ردیف رویداد، مشخصات مجوز یا ویرایش دسترسی |
| صفحه | مسیر، داده و ترکیب اجزا |

نام پوشه‌ها اجباری نیست؛ مسئولیت‌ها و مرزها باید روشن باشند.
یک Button مشترک را برای رنگ یا اندازهٔ جدید توسعه دهید؛ نسخهٔ جدا برای هر صفحه نسازید.

## ردیوس‌ها

| توکن | مقدار پیش‌فرض | استفاده |
| --- | --- | --- |
| --radius-none | 0 | سطح یکپارچه و بدون گوشه |
| --radius-sm | 4px | جزئیات کوچک داخلی |
| --radius-control | 8px | دکمه، ورودی و انتخابگر |
| --radius-surface | 12px | کارت، منو و popover |
| --radius-dialog | 16px | دیالوگ و drawer |
| --radius-full | 9999px | آواتار و badge کپسولی |

یکپارچگی یعنی یک نقش، یک توکن؛ همهٔ عناصر الزاماً یک ردیوس ندارند.
اگر محصول قبلی مقیاس منسجم دارد، یک‌بار آن را مرکزی نگاشت و ثبت کنید.
زبان یا تم نباید اندازه و هندسهٔ اجزا را تغییر دهد.

## سایر توکن‌ها

نمونهٔ CSS شامل فاصله‌های ۴، ۸، ۱۲، ۱۶، ۲۴ و ۳۲ پیکسل، متن پایهٔ ۱۶ پیکسل،
ارتفاع کنترل ۴۰/۴۴/۴۸، حلقهٔ فوکوس، لایه‌ها، سایه و حرکت کوتاه است.
مقادیر نمونه باید با تراکم واقعی محصول سازگار شوند.
فهرست دقیق و قابل اجرا در [tokens.css](../skills/bilingual-ui-system/assets/tokens.css) قرار دارد.

نام‌های معنایی مانند `--color-surface` و `--color-text` را در کامپوننت مصرف کنید.
کد رنگ مستقیم و مقادیر دلخواه گوشه در فایل صفحه قرار ندهید.
در Tailwind باید نگاشت مرکزی توکن را بسازید؛ از کلاس رنگ خام و rounded دلخواه دوری کنید.

## API و وضعیت‌ها

اندازه و نوع ظاهری را با API مشخص مثل `size` و `variant` تعریف کنید.
برای بارگذاری، غیرفعال بودن و خطا معنای جدا داشته باشید؛ مجموعهٔ booleanهای متناقض نسازید.
Button باید default، hover، active، focus-visible، disabled و loading داشته باشد.
Input علاوه بر این‌ها، invalid، read-only، توضیح و ارتباط خطا با فیلد را پوشش می‌دهد.
Dialog باید نام قابل دسترس، مدیریت فوکوس، Escape، اسکرول و بازگشت فوکوس داشته باشد.

از [قالب مشخصات کامپوننت](../templates/Component_Spec_FA.md) برای ثبت قرارداد استفاده کنید.
