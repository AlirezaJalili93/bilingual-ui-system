## هدف

تبدیل خواسته‌های طراحی به قرارداد قابل تکرار برای عامل توسعه، توسعه‌دهنده و بازبین.
قرارداد باید هنگام ساخت صفحه، تغییر CSS، توسعهٔ کامپوننت، اصلاح فرم و بررسی رابط خوانده شود.
کار صرفاً بک‌اند، الزام به ساخت یا بازنویسی رابط ندارد.

## خروجی‌های واقعی

چهار پوشهٔ اسکیل، نصب‌کنندهٔ Python، CSS نمونه، اسکریپت تم، اسکنر و تنظیمات آن،
نمونهٔ قواعد پروژه، مستندات و قالب‌های اجرایی تحویل داده شده‌اند.
اسکیل یک دستورالعمل کاری است؛ کتابخانهٔ آمادهٔ تمام کامپوننت‌های React/Vue نیست.
برای نمونه، قواعد رفتار Dialog مشخص است، اما خود Dialog باید با کتابخانه و کد موجود پروژه پیاده شود.

## انتخاب‌های پیش‌فرض

زبان پیش‌فرض ورود، تقویم، منطقهٔ زمانی، ارز و تراکم محصول باید در پروژه مشخص شوند.
بسته از وجود زبان فارسی، تقویم یا منطقهٔ زمانی کسب‌وکار را حدس نمی‌زند.
پالت خنثی نمونه از `#324462` در تم روشن استفاده می‌کند؛ برند محصول در محل توکن مرکزی قابل تغییر است.

## چه چیزی خودکار انجام نمی‌شود؟

نصب‌کننده CSS را وارد برنامه نمی‌کند، فونت تجاری دانلود نمی‌کند،
سامانهٔ ترجمه نصب نمی‌کند، کتابخانهٔ رابط را تعویض نمی‌کند و تنظیمات اجباری CI را فعال نمی‌کند.
این مراحل جزو ادغام در پروژه‌اند و در راهنمای نصب و بررسی توضیح داده شده‌اند.
