## نکتهٔ نسخه‌ها

نصب‌کنندهٔ مستقل داخل بسته دقیقاً از فایل فعلی تحویل‌شده گرفته شده است.
منابع چهار اسکیل نیز از نسخه‌های نصب‌شدهٔ فعلی کپی شده‌اند.
ممکن است منابع اسکیل دارایی متادیتایی مانند icon داشته باشند که snapshot قبلی نصب‌کننده آن را منتقل نکرده؛
این دارایی در قرارداد رابط نقشی ندارد. snapshot جدید از منابع، با فرمان export تولید می‌شود.

README مسیر شروع مطالعه است. مستندات ۰۱ تا ۱۱ استفاده و قرارداد را توضیح می‌دهند؛
این فایل نقشهٔ مسیرهاست. فهرست کامل فایل‌های نسخه همراه هش در manifest.json قرار دارد.
