# بستهٔ کامل رابط کاربری فارسی و انگلیسی

**نسخهٔ بسته: 1.1.0 — تاریخ آماده‌سازی: ۲۰۲۶/۱۱/۰۱**

این بسته شامل چهار اسکیل، نصب‌کنندهٔ قواعد پروژه، نمونهٔ فایل‌های قواعد، منابع طراحی،
مستندات Markdown و قالب‌های قابل استفاده در پروژه است. قاعدهٔ جاستیفای نیز در آن اعمال شده است.

## شروع سریع

1. پوشه را از ZIP خارج کنید.
2. [راهنمای نصب](docs/03_Installation_FA.md) را بخوانید.
3. دستور زیر را از همین پوشه برای پروژهٔ خود اجرا کنید؛ ابتدا حالت پیش‌نمایش:

```bash
python3 Bilingual_UI_Rules_Installer.py --project "/path/to/project" --dry-run
python3 Bilingual_UI_Rules_Installer.py --project "/path/to/project"
```

در ویندوز می‌توانید `py` را جایگزین `python3` کنید.
نصب قواعد به‌تنهایی رابط برنامه را تغییر نمی‌دهد؛ اتصال CSS، فونت و مدیریت تم باید در برنامه انجام شود.

## قرارداد کوتاه

- فارسی: `lang=fa`، `dir=rtl`، فونت دارای مجوز ایران‌یکان.
- انگلیسی: `lang=en`، `dir=ltr`، فونت پیش‌فرض سیستم.
- متن توضیحی چندخطی: جاستیفای؛ خط آخر هم‌جهت زبان.
- کامپوننت مشترک و توکن مرکزی؛ ردیوس کنترل ۸، سطح ۱۲، دیالوگ ۱۶ پیکسل.
- دو مجموعهٔ کامل توکن روشن/تاریک و انتخاب مستقل `light / dark / system`.
- پذیرش با بررسی فارسی روشن، فارسی تاریک، انگلیسی روشن و انگلیسی تاریک.

فایل تجاری ایران‌یکان همراه بسته نیست. پوشهٔ `skills` نسخهٔ قابل انتقال اسکیل‌هاست؛
خارج کردن ZIP به‌تنهایی آن‌ها را در یک ابزار نصب یا فعال نمی‌کند.
